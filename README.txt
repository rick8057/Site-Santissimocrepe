# Santíssimo Crepe

Site institucional do Santíssimo Crepe, serviço de crepes preparados na hora para eventos em Florianópolis e região. O projeto apresenta a marca, mostra fotos dos produtos e da experiência de atendimento, e facilita o contato para pedidos de orçamento.

## O que o site oferece

- Apresentação do serviço e da experiência Santíssimo Crepe.
- Galeria de imagens e vídeo de atendimento.
- Contato rápido por WhatsApp e Instagram.
- Formulário de interesse integrado ao Google Forms.

## Tecnologias

O site é estático, feito com HTML, CSS e JavaScript. Não requer instalação de dependências nem servidor de aplicação.

## Publicação

O repositório inclui um fluxo do GitHub Actions para publicar o conteúdo no GitHub Pages a cada atualização da branch `main`. Para hospedar em outro serviço, como a Locaweb, envie os arquivos do projeto preservando a estrutura de pastas. O arquivo inicial é `index.html`.

## Formulário

O formulário é incorporado do Google Forms e precisa de conexão com a internet para carregar e enviar respostas.
